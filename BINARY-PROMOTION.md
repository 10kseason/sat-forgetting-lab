# Can we safely delete one literal from a clause?

Take an explicit 2-CNF $B$ and a clause $C$ of arbitrary width on the same variables. The target is a 2-CNF description of $B\land C$ that agrees on every assignment to the original variables. A reusable test either produces such a description or returns three models disproving the existence of any such description, even with existentially quantified helper bits. [Implementation](binary_promotion.py) · [Tests](test_binary_promotion.py)

## One clause

Normalize repeated literals and discard a tautology. Starting with $L=C$, try each surviving literal $\ell$ in turn. Test $B$ with $\ell$ true and every other literal of $L$ false, using a 2-SAT solver with unit assumptions. When this is infeasible, remove $\ell$. This removal preserves $B\land L$ since the assignments lost by deleting $\ell$ are exactly the ones just tested. A feasible test returns a model in which $\ell$ alone satisfies the current $L$. It continues to satisfy $\ell$ alone when other literals are removed, so a single scan suffices.

If the remainder has width at most two, return $B$ with this remainder added. Otherwise choose the saved witnesses for three distinct surviving literals. They all satisfy the original formula. For every literal in the final remainder, at most one witness satisfies it. Therefore their coordinatewise majority falsifies the remainder. It still satisfies $B$, since in a binary clause a majority falsifying both literals would require at least one of the three models to falsify both. The same argument covers units. Equivalence of all deletion steps then makes the majority falsify the original $C$ as well.

Existentially projected 2-CNFs are also closed under majority. Extend the three models individually, take the majority of the three full assignments and restrict to the original variables. The resulting extension would witness feasibility of the very assignment just rejected. This proves completeness of the single-clause test. It uses at most the original width in calls to 2-SAT and returns either a formula on the original variables or a three-model certificate. The argument includes unsatisfiable backgrounds and empty clauses. [Lean theorem for majority and existential encodings](Formal/ClauseMajority.lean) · [Related work](RELATED-WORK.md)

## Repeating the test on a whole formula

Put all existing binary clauses, units and empty clauses in $B$. For each wider clause, apply the single-clause test relative to the current $B$. If successful, remove the original clause from the pending list and add the returned binary clause to $B$. Retry the pending list until a full pass makes no change. The conjunction of the backbone and the pending clauses remains equivalent to the complete input at every step. If every clause is absorbed, a final 2-SAT call decides the original problem and returns a model in its original variables. With $m$ pending clauses and maximum width $w$, at most $(m+1)mw$ calls to 2-SAT suffice.

The set of absorbed clause IDs at full saturation is independent of order. Given any set $S$ of previously absorbed original clauses, the current background represents exactly the original binary background conjoined with those clauses. If another clause $C$ can be absorbed at $S$, it remains absorbable at any reachable superset $T$: conjoin a 2-CNF for the background at $T$ with the short clause obtained at $S$. The resulting expression represents the stronger background together with $C$. Completeness of the one-clause test now applies. Inducting over a sequence of promotions shows that every terminal saturated run contains the choices of any other run. Consequently the terminal backgrounds represent the same function even if their binary clauses differ syntactically.

This procedure has a concrete limit. With empty $B$, the two clauses $(a\lor b\lor c)$ and $(a\lor b\lor\neg c)$ both fail the single-clause test. Their conjunction nevertheless equals $(a\lor b)$. The three witnesses for an individual rejection need only satisfy that clause and the current background. Another pending clause can exclude a witness.

## Schedules that choose a deletion without inspecting the input

Suppose a predetermined schedule removes one literal from each of $m$ ternary clauses before solving the result as 2-SAT. Use disjoint positive triples and binary-background units that force exactly one literal true in each triple. Every one of the $3^m$ possible patterns is satisfiable. Any given schedule preserves exactly $2^m$ patterns, since deleting the sole true literal from even one clause loses the solution. A fixed family covering all patterns therefore needs at least $\lceil(3/2)^m\rceil$ schedules. The pins themselves let an input-aware procedure choose safe deletions immediately. The schedule problem here is the known covering of a ternary cube by binary subcubes. [Kuang and Wang, Eq. (1), preprint](https://arxiv.org/html/2608.13252)

### Correlating deletions gives a complete solver

Write $m$ for the number of ternary clauses remaining after promotion. For a satisfying assignment, select one true position in each clause. This gives a ternary word. A schedule differing from that word at every coordinate keeps all those true literals. Conversely, a model of any shortened instance satisfies the original CNF. A family covering all ternary words therefore gives an exact finite algorithm using a 2-SAT solve per schedule. Random shortening followed by 2-SAT is an established algorithm. The deterministic construction here uses Moser and Scheder's greedy block covers with logarithmic block length and polynomial preprocessing. The returned assignment uses the original variables. [Random shortening, MIT 6.S078, Theorem 1.1](https://people.csail.mit.edu/virgi/6.s078/lecture3.pdf) · [Moser and Scheder, Lemmas 14–15](https://www.tu-chemnitz.de/informatik/theoretische-informatik/publications/2011-STOC-full-derandomization.pdf) · [Solver](ternary_schedules.py) · [Cover and solver tests](test_ternary_schedules.py)

For two clauses the schedules 00, 11 and 22 suffice because two target digits omit at least one of the three symbols. For three clauses, the five schedules 000, 011, 101, 110 and 222 suffice. The tests check every target. Concatenating block schedules lets the solver try correlated choices inside each block.

For a block of length $b$, every target belongs to $2^b$ of the $3^b$ possible schedules. Some schedule covers at least a $(2/3)^b$ fraction of any residual target set. Greedily choosing the largest intersection leaves at most $3^b\exp(-t(2/3)^b)$ targets after $t$ iterations. Thus $O(b(3/2)^b)$ schedules suffice per block. All intersections can be calculated explicitly in time polynomial in $3^b$. For large $m$, use $b=\lfloor\log_3(m)/2\rfloor$ and a shorter final block. The product cover has at most

$$
(3/2)^m\exp\bigl(O((m/b+1)\log(b+1))\bigr)=(3/2)^{m+o(m)}
$$

schedules. Block construction and the work per scheduled 2-SAT call are polynomial in the input size. The product is enumerated without storing the full product cover. Exponential worst-case enumeration remains; a budget-limited run can return UNKNOWN. If $m=O(\log N)$ for input size $N$, the whole algorithm is polynomial. The covering paper gives a tighter bound for the size of an unrestricted cover. [Kuang and Wang, Eq. (2) and Theorem 1.2](https://arxiv.org/html/2608.13252)

### A matching exponential base for this solver after promotion

For any sufficiently large desired residual clause count $M$, choose the smallest $t$ with $\binom t3\ge M$ and set $h=M-4t$. Then $t=O(M^{1/3})$ and $h>0$. Pin each of $t$ data variables $x$ true with four clauses $(x\lor\pm a\lor\pm b)$ using every sign combination on a fresh pair $a,b$ for that variable. For the remaining $h$ target stages use distinct increasing triples of data-variable indices. Pick one position per triple and make just that literal positive. Every model of the pins now has exactly that true position in the target. Each of the $3^h$ choices yields a satisfiable instance. The whole family has the same unsigned incidence and clause order.

All $M$ clauses have three distinct variables and the initial binary background is empty. In each individual clause, each literal can be its sole true literal, so the promotion pass leaves the instance intact. Sorting a clause by variable index preserves the target positions. A fixed omission schedule can retain a model on at most $2^h$ members of this family. Any prefix of fewer than $(3/2)^h$ content-independent schedules therefore misses a satisfiable member. The implemented solver uses the same ordered schedules at a given $M$ and stops on its first successful 2-SAT call. On some such member it must make at least $\lceil(3/2)^{M-O(M^{1/3})}\rceil$ calls, where the concrete exponent is $M-4t$.

Together with the block-cover upper bound, the worst-case number of schedule solves has exponential base $3/2$ in the residual ternary clause count. This bound concerns positional sampling with the specified preprocessing. Reading the pin gadget, for example, reveals which literal will be true. For general 3-SAT, Eppstein's Corollary 3.1 already gives a stronger algorithm using the same parameter, with an exponential term of $1.3645^m$. [Eppstein, SODA 2001](https://ics.uci.edu/~eppstein/pubs/Epp-SODA-01.pdf)
