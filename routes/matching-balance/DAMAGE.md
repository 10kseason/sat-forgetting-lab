# A wrong bit and a failed local constraint give different decoding problems

Each logical bit in the twelve-vertex substitution appears in four signed copies. The six valid block words have minimum Hamming distance four. One adversarial bit error is correctable; more generally, majority decoding works if at most one of the four copies of each logical bit is flipped. Two errors in a single group of four can produce a tie between valid words at distance four. This is ordinary repetition-code decoding. [Lean distance identity](../../Formal/BlockDamage.lean)

Now suppose a physical state fails just one of the thirteen **constraints**. Hexadecimal state f18 fails only (8,9,10), yet it is at Hamming distance **six from every valid block word**. Knowing the number of failed checks alone does not give the distance-one correction guarantee. [Lean counterexample](../../Formal/BlockDamage.lean)

## How many violations survive the reduction?

Let $u(H)$ be the minimum number of monochromatic triples in a four-round source and $T(H)$ its twelve-vertex substitution. Extend the six-state local encoding to all three-bit inputs by sending 000 to 7c2 and 111 to 83d. The thirteen internal triples then have exactly the violation count of the single source triple, including the monochromatic inputs. The port values still encode the logical tuple, up to the one lane-wide complement. Every assignment lifted this way preserves its total number of violations. [Finite cost and port identities](../../Formal/BlockDamage.lean)

For the converse, take an arbitrary physical assignment. For each logical position, undo the known signs in its three external copies and take their majority. In a locally valid block this changes no port and satisfies the source triple. In an invalid block the three majority decisions disagree with at most three external ports in total, and the rounded source triple can add at most one violation. Each changed port occurs in just one external triple. If there are $e$ external violations and $i$ internal violations, there are at most $i$ invalid blocks, so the rounded source has at most $e+4i$ violations.

Consequently $u(H)/4\le u(T(H))\le u(H)$. Since the construction quadruples the number of triples, the minimum violated **fraction** of a nonempty output lies between one sixteenth and one quarter of the source fraction. The factor four is an upper bound from this rounding proof. Global optimum counts can differ: the nine-point affine plane has minimum two (the complete-graph cut bound is attained by a four-versus-five split), while its 36-vertex output has minimum one. The output is unsatisfiable by the exact reduction, and the explicit physical mask a4da4d1e2 violates only one triple in the encoder's vertex order. [Reference checks](damage.py)
